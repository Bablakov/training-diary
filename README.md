# Дневник тренировок

Программы тренировок, план наперёд, запись в зале и статистика. Одно приложение для всех устройств:

- **iPhone и компьютер**: сайт https://bablakov.github.io/training-diary/. На iPhone открой его в Safari → «Поделиться» → «На экран „Домой“».
- **Android и Windows**: установщики в [Bablakov/training-diary-app](https://github.com/Bablakov/training-diary-app) (там же ссылки для всех устройств).

Всё работает без интернета: данные хранятся на самом устройстве. Синхронизация через GitHub нужна только для того, чтобы план, составленный на компьютере, оказался на телефоне, а тренировки с телефона — на компьютере.

## Что умеет

- **Тренировка.** Дата, день недели и время начала записываются сами. Разминка по умолчанию: начать, закончить сразу всеми кружками, пропустить. Несколько упражнений одновременно, у каждого своё время начала и конца. Подход отмечается галочкой, к нему оценка (легко, нормально, тяжело), заметка и дроп. Над подходом прошлый результат: зелёный, если было легко, красный, если тяжело. Самочувствие до и после тренировки (1–5), отзыв на следующий день.
- **План.** Очередь тренировок без дат: набираешь на одну или две недели вперёд, в зале берёшь следующую или любую. Каждая тренировка в плане — копия программы, которую можно изменить под конкретный раз.
- **Программы.** Подходы задаются одинаковыми, весом на каждый подход или процентом от одноповторного максимума (ПМ). Связки из нескольких упражнений подряд (дроп-сеты). Подсказки по весу по прошлой тренировке.
- **История и статистика.** Тоннаж, отдых между подходами (в начале и в конце тренировки), из чего состоит тренировка по времени, максимумы базовых упражнений, вес тела, средняя длительность, залы.
- **Перенос данных одним файлом** («Справочник» → «Перенос данных»): отправь себе в Telegram и открой на другом телефоне. Объединение не удаляет записи, а берёт более свежую правку.
- Четыре стиля оформления: Тетрадь, Зал, Минимал, Спорт.

## Синхронизация через GitHub

Данные лежат в **приватном** репозитории `Bablakov/training-data`: каждая запись отдельным файлом `data/<коллекция>/<id>.json`. Программа, изменённая на компьютере, и тренировки, записанные на телефоне, не мешают друг другу. Если одну запись правили на двух устройствах, остаётся более свежая правка.

Токен (один раз на каждое устройство):

1. GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: **Only select repositories** → `training-data`.
3. Permissions → Repository permissions → **Contents: Read and write**.
4. Скопируй токен и вставь в приложении: «Справочник» → «Синхронизация через GitHub» → «Проверить доступ».

Токен хранится только на устройстве и в экспорт не попадает.

## Разработка

```
npm install
npm run dev          # http://localhost:5173/training-diary/
npm test             # тесты синхронизации
npm run build        # сайт (dist/), выкладывается GitHub Actions при push в main
npm run apk          # Android: android/app/build/outputs/apk/release/app-release.apk
npm run exe          # Windows: desktop/release/training-diary-X.Y.Z-setup.exe (сначала `npm install` в desktop/)
```

Для APK нужны `JAVA_HOME=C:\Tools\jdk-17`, `GRADLE_USER_HOME=D:\Tools\gradle-home` и `android/local.properties` с `sdk.dir=D:/Tools/android-sdk`. Ключ подписи — `%APPDATA%\training-diary\android-keystore.properties` (вне репозитория).

Новая версия: поднять `version` в `package.json` и `desktop/package.json` (версия общая для сайта, APK и exe), `npm run apk`, `npm run exe`, push, затем релиз в **training-diary-app** с файлами под постоянными именами `training-diary.apk` и `training-diary-setup.exe` (на них ведут ссылки «latest/download» и проверка обновлений в приложении), дописать CHANGELOG там.

`prototype/` — кликабельный прототип, по которому согласовывался интерфейс.
